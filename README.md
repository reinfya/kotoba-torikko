# ことばとりっこ(公開手順)

## GitHub に置いて公開する(スマホのブラウザでもできます)

1. GitHub にログインし、新しいリポジトリを作る(名前の例: `kotoba-torikko`、**Public**)
2. 「Add file」→「Upload files」で `index.html` をアップロードして「Commit changes」
   - 更新するときも同じ手順です(同じ名前のファイルは上書きされます)
3. 「Settings」→「Pages」で Branch を `main` / `(root)` にして Save
4. 1〜2分後に `https://(GitHubユーザー名).github.io/kotoba-torikko/` で開けます

## 遊び方(オンライン)

1. 上のURLを開き、「2台でオンライン対戦」→「部屋をつくる」
2. 「LINEで送る」を押して、友だちにリンクを送る(LINEに移っても部屋は残ります)
3. 友だちがリンクを開くと、自動で同じ部屋に入って始まります

## 仕様

- ログイン不要。URLを知っている人は誰でも遊べます。検索には出にくい設定です。
- 通信は、無料の公開MQTTブローカー(EMQX と HiveMQ の2か所に同時接続)を使います。
  送信回数の上限は設けられていません。部屋コードを知っている人は、その部屋の通信を見られます。
- 各席の最新の状態をブローカーに置いておくので、画面を離れたり再読み込みしたりしても、同じ部屋にもどれます。
- 画面下の小さな「通信 A○ B○」は接続状態です。○は接続中、×は未接続です。両方×のときは、ネットワークがつながっていません。
- 手札は各自の端末の中だけにあり、相手には送られません。
